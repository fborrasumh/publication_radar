# Publication Radar

**Descubre revistas reales sobre cualquier temática y sigue sus últimos artículos.**

Aplicación web de un solo fichero (HTML/JS, sin backend). Busca revistas relevantes
en **OpenAlex** y **PubMed** a partir de una temática libre, permite seleccionar las
que se quieren seguir y recupera artículos recientes, marcando los ya vistos.

## Uso

Abre <https://fborrasumh.github.io/publication_radar/> o descarga `index.html` y
ábrelo con doble clic en cualquier navegador.

- Requiere una **API key de OpenAI** (obligatoria).
- OpenAlex y PubMed funcionan sin clave; añadir la clave de OpenAlex y un email de
  contacto para PubMed aumenta la cuota.
- Todo (claves, revistas seguidas, historial de vistos) se guarda **solo en
  `localStorage`** del navegador. No hay cuenta, servidor ni sincronización.
